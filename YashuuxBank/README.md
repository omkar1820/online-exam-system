# 🏦 Bank Account Manager
### Java Mini Project — Apache NetBeans

---

## Features
- ✅ Create new bank accounts (Savings / Current / Fixed Deposit)
- ✅ Delete and Edit accounts
- ✅ Deposit money
- ✅ Withdraw money (with balance validation)
- ✅ Transfer funds between accounts
- ✅ View full transaction statement per account
- ✅ Search accounts by holder name
- ✅ Live total funds display

---

## How to Open in Apache NetBeans

1. Open **Apache NetBeans IDE**
2. Go to **File → Open Project**
3. Browse to the `BankAccountManager` folder and select it
4. Click **Open Project**
5. Right-click the project → **Run** (or press `F6`)
